
# Link Space

A minimal, responsive link hub for my projects, portfolio, and social profiles.

## Overview

Link Space brings together my selected projects and online presence in one clean, easy-to-navigate place.

## Features

- Minimal, premium dark design
- Fully responsive layout
- Curated project showcase
- Dynamic project rendering
- Featured project highlighting
- Project status indicators
- Quick access to social profiles
- Copy page URL functionality
- Custom SVG favicon
- Optimized mobile and desktop typography
- Easy project management through JavaScript

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
link-space/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── favicon.svg
    └── og-image.png
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/ayush-rathour/link-space.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## Customization

Update the `projects` array in `script.js` to add, edit, reorder, or remove projects.

## Deployment

Deployed using Cloudflare Pages.
